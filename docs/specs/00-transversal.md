# 00 — Requisitos transversais

- **Estado:** Vigente
- **Fase:** todas · **ADRs:** 0002, 0003, 0006, 0007

Requisitos que valem para toda feature. As demais specs citam este documento em vez de
repetir.

## Critérios de aceite (EARS)

| id  | critério                                                                                                                                                                                                                                              | prova                                                                                                                                                                                                                                                                                                             |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T1  | O kernel DEVE aceitar mutação do documento apenas por transação reversível.                                                                                                                                                                           | `cargo test --manifest-path kernel/Cargo.toml --doc` (doctests `compile_fail` de `neocad-model`)                                                                                                                                                                                                                  |
| T2  | QUANDO uma transação é desfeita, o documento DEVE voltar a produzir o mesmo DXF, byte a byte, que produzia antes dela.                                                                                                                                | `cargo test --manifest-path kernel/Cargo.toml -p neocad-io --test undo_bytes`                                                                                                                                                                                                                                     |
| T3  | O mesmo documento, gravado pela mesma versão do NeoCAD, DEVE produzir os mesmos bytes em Linux e em Windows, as plataformas suportadas.                                                                                                               | `cargo test --manifest-path kernel/Cargo.toml -p neocad-io --test round_trip` (em Linux e Windows na CI)                                                                                                                                                                                                          |
| T4  | QUANDO o usuário salva um documento com conteúdo que o kernel não modela, o sistema DEVE abrir um diálogo que lista o que será descartado, por tipo e quantidade, com as opções salvar e cancelar; SE o usuário cancela, ENTÃO nada DEVE ser gravado. | `pnpm test -- cad-document` (conversão da perda) + `pnpm test:e2e -- save-loss` (a criar)                                                                                                                                                                                                                         |
| T5  | Toda variante de geometria do modelo DEVE ser lida e gravada em DXF.                                                                                                                                                                                  | `cargo test --manifest-path kernel/Cargo.toml -p neocad-io --test round_trip` com um teste de ida e volta por variante, escrito sobre `match` exaustivo de `Geometry` — variante nova sem leitura e gravação faz o teste deixar de compilar (a criar)                                                             |
| T6  | Toda comparação geométrica DEVE passar pelo `Tolerance` ou pelo predicado exato do ADR 0006; literal de tolerância em código de produção fora de `tolerance.rs` e `predicate.rs` é proibido.                                                          | script que varre o código fora de `#[cfg(test)]` atrás de literal de ponto flutuante não nulo com valor absoluto menor que `1e-2`, em notação decimal ou científica, e falha se achar (a criar, entra em `make kernel-check`)                                                                                     |
| T7  | As crates do kernel, exceto a fachada `neocad-wasm`, NÃO DEVEM depender de Tauri, DOM ou navegador; nenhuma crate, exceto `neocad-io`, DEVE ter dependência de licença copyleft.                                                                      | script sobre `cargo metadata` que falha se uma dependência normal violar uma das duas regras — copyleft = GPL, LGPL, AGPL, MPL, SSPL; navegador = `tauri*`, `wasm-bindgen`, `js-sys`, `web-sys` — vale para dependência normal, direta ou transitiva, alcançada sem passar por `neocad-io` (a criar, entra na CI) |
| T8  | Comandos digitados DEVEM ser aceitos em inglês e em português, com a grafia oficial de cada idioma.                                                                                                                                                   | `pnpm test -- command-line` (spec 08, C1)                                                                                                                                                                                                                                                                         |
| T9  | Toda mudança DEVE passar na CI em Linux e Windows antes do merge.                                                                                                                                                                                     | `gh pr checks <n>`                                                                                                                                                                                                                                                                                                |
| T10 | Toda fixture DEVE estar listada em `e2e/fixtures/ORIGEM.md` com origem (sintética ou pública) e licença.                                                                                                                                              | teste que falha se houver arquivo em `e2e/fixtures/` ou `kernel/*/tests/` sem linha no `ORIGEM.md` (a criar)                                                                                                                                                                                                      |

Duas regras são convenção conferida na revisão de PR, e não critério com prova
automática: a interface fica em português do Brasil, e nenhum dado de projeto de
terceiros entra no repositório (AGENTS.md §0.1).

## Requisitos não-funcionais de referência

Valores a confirmar por medição no spike de KV (spec 07) e depois fixados aqui:

- abrir um DXF de 100 mil entidades em até 5 s numa máquina de desenvolvimento comum;
- refletir na tela a edição de uma entidade em até 100 ms nesse mesmo desenho.
