# 05 — Edição 2D

- **Estado:** Vigente (E1–E13)
- **Fase:** K3, bloco C · **ADRs:** 0006 · **Transversais:** 00 (T1, T2, T6)

## Problema e resultado esperado

O desenhista de engenharia passa mais tempo modificando do que criando. O kernel sabe
mover, copiar, girar, espelhar, escalar, fazer paralela, aparar, estender, concordar e
chanfrar — sempre por transação reversível.

| operação  | comando EN | comando PT-BR  | apelido |
| --------- | ---------- | -------------- | ------- |
| mover     | `MOVE`     | `MOVER`        | `M`     |
| copiar    | `COPY`     | `COPIAR`       | `CO`    |
| girar     | `ROTATE`   | `ROTAC`        | `RO`    |
| espelhar  | `MIRROR`   | `ESPELHAR`     | `MI`    |
| escalar   | `SCALE`    | `ESCALA`       | `SC`    |
| paralela  | `OFFSET`   | `DESLOCAMENTO` | `O`     |
| aparar    | `TRIM`     | `APARAR`       | `TR`    |
| estender  | `EXTEND`   | `ESTENDER`     | `EX`    |
| concordar | `FILLET`   | `CONCORD`      | `F`     |
| chanfrar  | `CHAMFER`  | `CHANFRO`      | `CHA`   |

Os nomes vêm de [`08-comandos-autocad.tsv`](08-comandos-autocad.tsv). Esta spec cobre a
**operação no kernel**; a interação (pedir pontos, pré-visualizar) é da spec 08 e da fase
de UI/UX.

## Fora de escopo

Escala não uniforme (o modelo não tem elipse; volta com KP2). Aparo com todas as
entidades como aresta implícita (conveniência de interface). Concordância entre duas
polilinhas num só gesto. Esticar (`STRETCH`), alongar (`LENGTHEN`), quebrar (`BREAK`) e
unir (`JOIN`): ficam para spec própria, depois de K3. Concordância entre retas paralelas
(o AutoCAD une com semicircunferência): recusada por ora (E11).

| E13 | QUANDO duas retas são chanfradas com distâncias d1 e d2, cada reta DEVE ser aparada à distância correspondente do vértice e unida por um segmento; QUANDO as retas não se cruzam no trecho desenhado, o vértice DEVE ser o cruzamento das retas estendidas; SE alguma distância é negativa ou maior que o trecho disponível, ou SE as retas são paralelas, ENTÃO o chanfro DEVE ser recusado sem alterar o documento; distâncias zero DEVEM equivaler a estender até o vértice. | `cargo test --manifest-path kernel/Cargo.toml -p neocad-geometry fillet::tests::chanfro` e `cargo test --manifest-path kernel/Cargo.toml -p neocad-io --test undo_bytes chanfrar` |
